## Day 1 v1.0

* **Tokenization:** Used the `strtok` function to split the raw user input into a core command and its arguments (parameters) based on space characters.
* **Built-in Commands:**
  * Added `quit`, `exit`, and `leave` commands to terminate the shell.
  * Implemented a `print` and `write` command loop that outputs the provided parameters to test the argument parsing logic.

## Day 2 v1.1

* **System commands:** Used the `system` function to use Windows CMD built-in commands.
* **Built-in Commands:**
  * Added `clear` and `c` to clear Terminal.
  * Added `cd` command to change current working directory and `cd..` for exiting current working directory.
  * At the beggining it shows current working directory before ` >  `.
