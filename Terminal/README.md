# C Shell Project

This project is a custom terminal (shell) application built from scratch in C. The main goal is to learn to C language.

### How to Run
You can compile and run the code using GCC (MinGW or a native Linux compiler):

```bash
# Compile
gcc shell.c -o myshell

# Run (Linux/macOS)
./myshell

# Run (Windows)
myshell.exe
